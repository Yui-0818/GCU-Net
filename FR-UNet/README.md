# FR-UNet · 角膜溃疡分割基线

MIT 许可的 [FR-UNet](https://github.com/lseventeen/FR-UNet)（JBHI 2022）在本实验数据上的直接训练版本。**网络结构未做任何修改**，只适配了数据读取、采样、损失与推理方式。

详细的第一人称实验报告在项目根目录的 `docs/实验报告/2/实验二_FR-UNet_角膜溃疡分割.md`（不随代码仓库分发）。

## 任务与数据

- 输入：2592×1728 角膜荧光素染色图（灰度读取）。
- 输出：同尺寸二值掩膜，前景为溃疡。
- 数据：train 283 / val 36 / test 35；掩膜中 `0` 为溃疡、`255` 为背景，读取时反相。
- 标签极不平衡：全数据病灶面积占比中位数约 2%，测试集最高 24.5%。

## 方法要点

| 项目 | 设置 |
| --- | --- |
| 网络 | FR-UNet，单通道输入/输出，7.374 M 参数 |
| 切块 | 256×256，步长 128，共 73,580 块（含病灶 10.08%） |
| 采样 | 加权采样，每批约 50% 含病灶 |
| 损失 | CE + Dice（各 0.5） |
| 优化 | Adam，lr 1e-4，wd 1e-5，余弦退火 100 轮 |
| 批大小 | 4，每轮 400 步，混合精度 |
| 推理 | 512×512 分块、步长 448 重叠平均 |
| 指标 | Dice、IoU、AUC、Sen、Spe、Pre、Acc |

## 结果

训练 100 轮，约 3 小时 13 分钟，最佳验证结果出现在第 100 轮：

| 集合 | Dice | IoU | AUC | 敏感度 | 特异度 | 精确率 | 准确率 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 验证集（逐图平均） | 0.7309 | 0.6219 | 0.9926 | 0.8157 | 0.9891 | 0.7329 | 0.9809 |
| 测试集（逐图平均） | 0.7310 | 0.6244 | 0.9928 | 0.8568 | 0.9856 | 0.7369 | 0.9736 |
| 测试集（全局像素累计） | **0.8052** | **0.6739** | - | - | - | - | - |

- 测试集逐图 Dice 中位数 0.8102，35 张中 5 张低于 0.5。
- 阈值在验证集上选为 0.55；测试全局 Dice 0.8052，比 0.50 高 0.0010。测试集上事后扫描的 0.60 仅作参考。
- 病灶面积与 Dice 的相关系数 r = 0.3829；小病灶能否分割更多取决于形态与对比度。

## 收获

1. 不改网络结构，只修正掩膜极性、正样本重采样、Dice 损失和分块推理，模型就从全背景预测提升到测试集逐图 Dice 0.731。
2. 逐图平均 Dice（0.7310）与全局像素 Dice（0.8052）差 0.074，报告指标必须注明口径。
3. 极小的病灶也能取得 0.98 的 Dice，前提是边界清晰、对比度高；细线状病灶则几乎全漏，说明小目标难点在形态而非单纯面积。
4. 图像自带的红色椭圆和角膜缘会被模型当作捷径，数据层面的伪相关必须在建模前处理。
5. 显存、单类别 AUC 崩溃、DataParallel 开销、断点续训等工程问题直接决定长时训练能否完成。

## 在该数据上发现的问题

1. **红色椭圆成为捷径**：训练早期模型的概率图沿图像自带的红色椭圆响应，而不是只响应病灶。红环与标签无因果关系，是典型的伪相关。
2. **小病灶几乎分割不出**：面积占比低于 0.1% 的样本，模型往往整块漏检或把整个角膜缘当成病灶。
3. **89.92% 的训练切块为纯背景**：不做重采样时梯度被背景主导，必须配合正样本过采样与 Dice 类损失。
4. **整图推理显存溢出**：全分辨率结构在 2592×1728 上直接前向 OOM，必须分块。
5. **划分分布偏移**：测试集平均病灶面积是训练集的 2.5 倍，测试指标不能直接外推到小病灶场景。
6. **灰度化损失颜色对比**：荧光素的判别信息主要在绿通道相对红、蓝通道的增强，单通道输入丢失了这部分信息。
